# TaskManagerAPI

A simple *Task Management REST API* built using *Python Flask*.  
This API allows users to create, read, update, and delete tasks stored inside a JSON file.

---

## 🚀 Live API URL
Your API is successfully deployed on Railway:

🔗 https://taskmanagerapi-production-54f7.up.railway.app

---

## 📌 Features
- Add a new task  
- Get all tasks  
- Update an existing task  
- Delete a task  
- JSON file storage  
- Auto-deployed from GitHub using Railway

## 📡 API Endpoints

| Method | Endpoint | Description |
|--------|----------|-------------|
| GET | / | Check if API is running |
| GET | /tasks | Get all tasks |
| POST | /tasks | Create a new task |
| PUT | /tasks/<id> | Update a task |
| DELETE | /tasks/<id> | Delete a task |
